## Toolchain quirks

- **Tailwind CSS v4, CSS-first**: no `tailwind.config.*`. Theme lives in `src/app/globals.css` via `@theme`. CSS is compiled by the `@tailwindcss/turbopack` loader wired in `next.config.ts` — if CSS classes stop applying after config changes, check that rule.
- **shadcn v4 "base-nova" style** (`components.json`): UI primitives in `src/components/ui/` are built on **@base-ui/react, not Radix**. When editing or adding components, match the Base UI imports; don't copy Radix-based snippets from older shadcn docs/blogs.
- `cn` is the **npm package `cn`** (a clsx/tailwind-merge wrapper), not a local utility. `src/lib/utils.ts` merely re-exports it; either import works.
- shadcn components also pull styles from `shadcn/tailwind.css` (imported in `globals.css`).
- To add shadcn components: `npx shadcn add <component>` (config already points aliases at `src/`).
